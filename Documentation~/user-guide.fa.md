# راهنمای کاربر

## مدل ایمنی
- اسکن، تحلیل، پیش‌نمایش و خروجی گزارش فقط‌خواندنی هستند.
- با انتخاب پروفایل هیچ چیزی اعمال نمی‌شود. Apply به فشردن دکمه و تأیید در پنجرهٔ تأیید نیاز دارد.
- پیش از اولین نوشتن، یک snapshot به‌صورت JSON در `ProjectSettings/JP/AudioImportOptimizer/Snapshots/` ذخیره می‌شود. اگر ذخیره نشود، هیچ تغییری انجام نمی‌شود.
- assetهایی که تنظیمات مؤثرشان از قبل مطابق است، *Unchanged* گزارش می‌شوند و reimport نمی‌شوند.
- پس از بسته شدن بلوک editing، هر asset اعمال‌شده دوباره خوانده می‌شود؛ در صورت مغایرت نتیجه به *Failed* با توضیح تبدیل می‌شود.
- دسته با `AssetDatabase.StartAssetEditing/StopAssetEditing` احاطه شده و `StopAssetEditing` در بلوک `finally` است.

## تب‌ها
**Overview** — تعداد کل assetها، assetهای منطبق با قانون، هشدارها، خطاها، تغییرات در انتظار، زمان آخرین اسکن و هشدار کهنه‌بودن نتایج (وقتی assetهای صوتی پس از اسکن تغییر کرده‌اند).

**Scan** — *Folders* (هر پوشه در یک خط؛ پوشهٔ ناموجود گزارش می‌شود)، *Exclude* (پیشوند پوشه‌ها)، *Extensions* (خالی = هر فرمت صوتی که Unity به‌عنوان AudioClip ایمپورت می‌کند)، *Include Packages* (به‌طور پیش‌فرض خاموش؛ assetهای پکیج اغلب فقط‌خواندنی‌اند). اسکن زمان‌بندی‌شده است (حدود ۱۰ میلی‌ثانیه در هر tick) تا Editor روان بماند.

**Profile** — فیلد شیء، *Create starter profile…*، *Edit in Inspector*، *Re-run analysis* (تحلیل دادهٔ اسکن‌شده بدون اسکن دوباره)، خلاصهٔ قوانین و پیام‌های اعتبارسنجی.

**Results** — جست‌وجو (مسیر یا دسته)، فیلتر شدت، مرتب‌سازی (مسیر، شدت، دسته، تغییرات)، گزینهٔ *Has changes*، چک‌باکس انتخاب هر ردیف، *Select all shown*، *Clear selection*، *Exclude selected*، *Include selected*. فهرست virtualized است و هزاران asset را روان نمایش می‌دهد. کلیک روی asset قانون، توضیح اولویت و یافته‌ها را نشان می‌دهد؛ *Ping asset* فقط با همان کلیک clip را بارگذاری می‌کند.

**Changes** — جدول dry run با دو چک‌باکس در هر ردیف (asset، تغییر). *Include all*، *Include safe only* (تغییراتی که override پلتفرم را حذف می‌کنند کنار گذاشته می‌شوند)، *Exclude all*. علامت `(!)` یعنی تغییر auto-safe نیست. هر تغییر باعث reimport همان asset می‌شود.

**Apply & Restore** — دامنهٔ اعمال (همهٔ تیک‌خورده‌ها یا فقط assetهای انتخاب‌شده در Results)، شمارش تغییرات، هشدارها (خطای پروفایل، اسکن ناقص یا نتایج کهنه Apply را مسدود یا علامت‌گذاری می‌کنند)، فهرست آخرین عملیات با نتایج *Applied / Skipped / Failed / Unchanged*، فهرست snapshotها و بازیابی. *Reveal snapshot folder* پوشهٔ بازیابی را باز می‌کند.

**Reports** — JSON و HTML. محتوا: نسخهٔ پکیج و Unity، زمان اسکن (UTC)، دامنه، نام پروفایل، مجموع‌ها، تعداد هشدار/خطا، assetهای نیازمند تغییر، تعداد applied/skipped/failed/unchanged و همهٔ یافته‌ها با مقدار فعلی و پیشنهادی. فقط مسیرهای نسبی پروژه نوشته می‌شود و فایل در مکانی که شما انتخاب می‌کنید ذخیره می‌شود.

**Help** — خلاصهٔ روند کار، مستندات، وب‌سایت، سازنده و راه ارتباطی.

## یافته‌ها
| کد | شدت | معنا |
|---|---|---|
| AIO001 | شدت mismatch قانون | تنظیمی در Default با قانون فرق دارد |
| AIO002 | Error | از فرمت فشرده‌سازی ممنوع استفاده شده |
| AIO003 | Error | importer خوانده نشد |
| AIO004 | Info | هیچ قانونی منطبق نیست |
| AIO005 | Warning | دو قانون در اولویت و specificity مساوی‌اند |
| AIO006 | Info | فرمت asset با اکثریت دستهٔ خود فرق دارد (حداقل ۳ asset و اکثریت قطعی) |
| AIO007 | شدت mismatch قانون | override پلتفرم با قانون فرق دارد |
| AIO008 | شدت mismatch قانون | override پلتفرم باید ساخته یا حذف شود |

## نکات کارایی
اسکن فقط metadata ایمپورتر را می‌خواند (clip بارگذاری نمی‌شود). Apply هر asset تغییرکرده را reimport می‌کند و در دسته‌های بزرگ ممکن است چند دقیقه طول بکشد. حجم فایل منبع جایگزین ارزان برای طول clip است، نه طول واقعی. پکیج صرفه‌جویی حافظه یا حجم build را تخمین نمی‌زند، چون این کار نیازمند profiling یا build است.

## فایل‌های نوشته‌شده
| مکان | محتوا | زمان |
|---|---|---|
| `ProjectSettings/JP/AudioImportOptimizer/Snapshots/snapshot-<id>.json` | snapshot بازیابی | پیش از apply و پیش از restore |
| `*.tmp` کنار snapshot | فایل موقت که سپس جابه‌جا می‌شود | فقط هنگام ذخیره |
| مکانی که شما انتخاب می‌کنید | گزارش‌ها | هنگام export |
| فایل `.asset` پروفایل | پروفایل‌ها | هنگام *Create starter profile…* |
هیچ cache، telemetry یا درخواست شبکه‌ای وجود ندارد. فایل‌های صوتی منبع هرگز حذف یا تغییر داده نمی‌شوند.
