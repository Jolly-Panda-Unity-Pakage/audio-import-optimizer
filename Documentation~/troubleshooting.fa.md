# عیب‌یابی

| مشکل | علت و راه‌حل |
|---|---|
| آیتم منو دیده نمی‌شود | پکیج کامپایل نشده است. خطاهای Console را رفع کنید و مطمئن شوید Unity نسخهٔ 6000.6 یا بالاتر است. |
| تست‌ها فهرست نمی‌شوند | پکیج را به `testables` در `Packages/manifest.json` اضافه کنید. |
| «No audio assets were found» | پوشه‌ها اشتباه‌اند، یک exclude یا فیلتر پسوند مانع شده است. پوشه‌ها باید نسبی پروژه باشند (`Assets/...`). |
| «Folder does not exist» | غلط املایی یا پوشهٔ حذف‌شده؛ آن پوشه رد می‌شود و بقیه اسکن می‌شوند. |
| «No rule matched» | معیارها با AND ترکیب می‌شوند؛ برای نادیده‌گرفتن، فهرست را خالی کنید؛ املای پوشه را بررسی کنید. |
| قانون اشتباه برنده می‌شود | متن توضیح اولویت در Results را بخوانید؛ `priority` را بالا ببرید یا معیار اضافه کنید. |
| دکمهٔ Apply غیرفعال است | تغییری در انتظار نیست، اسکن در جریان است، پروفایل خطا دارد، یا assetها پس از اسکن تغییر کرده‌اند (دوباره اسکن کنید). |
| نتیجهٔ *Failed*: «Verification failed» | Unity مقدار را نگه نداشته (فرمت برای آن پلتفرم پشتیبانی نمی‌شود). فرمت دیگری برای آن پلتفرم انتخاب کنید. |
| *Failed* روی `Packages/...` | assetهای پکیج فقط‌خواندنی‌اند. Packages را exclude کنید یا clip را به `Assets` کپی کنید. |
| تنظیم پلتفرم رد شد | override آن وجود ندارد و تغییر ساخت آن حذف شده بود. تغییر *PlatformOverride* را شامل کنید. |
| reimport زیاد | هر asset تغییرکرده reimport می‌شود. دسته‌های کوچک‌تر اعمال کنید (assetها را در Results انتخاب کنید). |
| Restore نتیجهٔ *Skipped* می‌دهد | asset حذف شده است. assetهای جابه‌جاشده با GUID پیدا می‌شوند. |
| Restore نتیجهٔ *Failed* می‌دهد | یکی از مقادیر ذخیره‌شده در این نسخهٔ Unity موجود نیست؛ پیام نام آن را می‌گوید. |
| snapshot نامعتبر است | فایل ویرایش شده یا با نسخهٔ جدیدتر پکیج نوشته شده است. snapshot را دستی ویرایش نکنید. |
| Undo کاری نمی‌کند | Undo نمی‌تواند تنظیمات importer را برگرداند؛ snapshot را بازیابی کنید یا از version control استفاده کنید. |
