# شروع سریع

## این ابزار چه می‌کند و چرا وجود دارد
با این ابزار می‌توانید تنظیمات import چندین AudioClip را هم‌زمان و ایمن بررسی و تغییر دهید: اسکن و پیش‌نمایش هرگز چیزی را تغییر نمی‌دهند و پیش از هر اعمال، یک snapshot بازیابی ذخیره می‌شود.

## نصب
۱. پوشهٔ پکیج را در `Packages/` پروژه کپی کنید (embedded package) یا از *Window > Package Manager > + > Add package from disk…* فایل `package.json` را انتخاب کنید. پس از انتشار مخزن، نصب با Git URL هم ممکن است.
۲. نیازمند Unity 6000.6 است و هیچ وابستگی‌ای ندارد.
۳. برای اجرای تست‌ها، `"testables": ["com.jollypanda.audio-import-optimizer"]` را به `Packages/manifest.json` اضافه کنید.

## باز کردن
`Tools > JP > Audio Import Optimizer`

## روند معمول کار
۱. **تب Profile** — *Create starter profile…* را بزنید (همیشه نام یکتا استفاده می‌شود و چیزی بازنویسی نمی‌شود) یا پروفایل موجود را تعیین کنید. قوانین نمونه به پوشه‌هایی مثل `Assets/Audio/Music` اشاره دارند؛ آن‌ها را در Inspector مطابق پروژهٔ خود ویرایش کنید.
۲. **تب Scan** — پوشه‌ها، مستثنیات و پسوندها را تنظیم و *Scan* را بزنید. نوار پیشرفت و دکمهٔ *Cancel scan* نمایش داده می‌شود. فقط metadata ایمپورتر خوانده می‌شود.
۳. **تب Results** — جست‌وجو، فیلتر و مرتب‌سازی؛ با کلیک روی یک asset، قانون برنده، دلیل برنده شدن و هر یافته (چه چیزی، چرا مهم است، تغییر پیشنهادی، ایمن بودن) را ببینید.
۴. **تب Changes** — dry run: asset، پلتفرم، تنظیم، مقدار فعلی ← پیشنهادی، قانون. با برداشتن تیک، asset یا تغییر تکی را حذف کنید.
۵. **تب Apply & Restore** — *Apply ticked changes…* ابتدا تأیید می‌گیرد، snapshot ذخیره می‌کند، تغییرات را می‌نویسد، assetهای تغییرکرده را reimport می‌کند، نتیجه را راستی‌آزمایی می‌کند و اسکن را تازه می‌کند.
۶. **بازیابی** — یک snapshot را انتخاب و *Restore this snapshot…* را بزنید (تأیید لازم است و پیش از آن پشتیبان ایمنی ذخیره می‌شود).
۷. **تب Reports** — خروجی JSON یا HTML.

## محدودیت‌ها در یک بند
Apply تراکنشی (transactional) نیست؛ Undo نمی‌تواند تنظیمات importer را برگرداند (از snapshot یا version control استفاده کنید)؛ *Normalize* ارائه نشده چون `AudioImporter` ویژگی عمومی قابل‌تأییدی برای آن ندارد؛ فقط پلتفرم‌های Standalone، iPhone، Android و WebGL بررسی می‌شوند.
