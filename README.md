# Audio Import Optimizer

> Unity Editor tool that analyzes audio import settings and applies configurable optimization profiles with dry-run previews and snapshots.

**Status:** 🛠️ In Development

## Why

Audio import settings are easy to get inconsistent across a project (load type, compression, sample rate, mono), which wastes memory and build size. Fixing it by hand is slow and risky.

## Who it is for

Indie developers and small studios shipping to mobile/WebGL/console where audio memory and size matter.

## Planned features

* Audio asset scanning and analysis
* Configurable optimization profiles
* Platform-specific import settings
* Validation and optimization recommendations
* Dry-run previews before applying changes
* Import settings snapshots and recovery
* Reports and batch processing

## First milestone (MVP)

Scan a folder, apply one profile with dry-run diff, one-click revert from snapshot, CSV/Markdown report.

## Compatibility

Target: 2021.3 LTS through current Unity 6. Final support will be confirmed before release.
